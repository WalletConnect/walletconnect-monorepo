# Contributing to WalletConnect Monorepo

Thanks for your interest in contributing!

## Quick start (browser)
1. Fork the repo and open your fork.
2. Use "Add file → Create new file" for small doc changes, or create a branch for code changes.
3. Commit to a new branch and open a Pull Request against `WalletConnect/walletconnect-monorepo:main`.

## Quick start (local)
1. Fork and clone:
   git clone git@github.com:<your-username>/walletconnect-monorepo.git
   cd walletconnect-monorepo
   git switch -c my-fix
2. Make changes, run tests if relevant, commit and push:
   git add <files>
   git commit -m "Short, clear message"
   git push -u origin my-fix
3. Open a PR and explain the change.

## Good first contributions
- Fix typos or small grammar issues in README/docs.
- Small improvements to package READMEs under `packages/`.
- Add or fix docs/example usage.

## PR checklist
- Describe what you changed and why.
- Keep PRs small and focused.
- If code changes, run `npm run check` from repo root.
